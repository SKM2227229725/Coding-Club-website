# 💻 Coding Club Website

Official **Coding Club Website** built to represent the club, its members, and all activities including past and upcoming events.

🌐 **Live Demo:**  
👉 https://coding-club-website-sepia.vercel.app/

---

## 📌 About the Project

This website is created for the **Coding Club** to provide a centralized platform where students can:

- Know about the Coding Club
- View Core & Junior Core Members
- Explore past events and achievements
- Stay updated with upcoming events
- Encourage juniors to join and learn coding

The project is lightweight, beginner-friendly, and built using **pure frontend technologies**.

---

## ✨ Features

### 👥 Members Section
- **Core Members**
  - Displays main club leaders
  - Shows roles and responsibilities
- **Junior Core Members**
  - Highlights junior team members
  - Encourages student participation and growth

---

### 📅 Events Section

#### 🔙 Past Events
- List of previously conducted events
- Event details and descriptions
- Showcases club experience and activities

#### ⏭️ Upcoming Events
- Information about future workshops, sessions, and hackathons
- Keeps members updated with schedules

---

### 📢 Announcements
- Important club updates
- Event notices and information

---

### 🎨 UI & Design
- Clean and simple design
- Fully responsive layout
- Easy navigation for users
